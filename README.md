# 🛸 天空之城 · 空中浮岛竞速经营

一款以**云海浮岛竞速**为核心玩法的经营模拟游戏。玩家经营一支空中竞速车队，在漂浮于云海的浮岛赛道上逐站参赛，赢取积分与奖金，改装飞艇、招募机师技工、达成赞助目标，向赛季之巅发起冲击。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务（server:4180 + vite:5204）
```

浏览器访问 **http://localhost:5204** 即可开始游戏。

> 若 5204 端口被占用，Vite 会自动切换到其他端口；后端 API 代理随之生效，无需手动修改。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3（`<script setup>`）+ Vite + Pinia |
| 后端 | Express + Node.js 内置 `node:sqlite` |
| 数据库 | SQLite（`server/sky.db`，首次启动自动建表并写入演示数据） |
| 启动 | `concurrently` 并行拉起前后端 |

## 玩法说明

1. **云海航线图**：主场景为云海浮岛赛季航线图，6 座浮岛依次排列。点击浮岛上的 **🚀 开赛** 进入分段竞速。
2. **四段竞速**：6 艘飞艇（玩家 + 5 名对手）依次通过 **起飞加速 → 穿云转向 → 云脊冲刺 → 风暴冲线** 四段，每段分别受飞艇的加速/转向/速度/耐久、已装备改装件、机师与技工状态、天气与部件健康影响；右侧 LIVE 榜按分段进度实时刷新名次。
3. **中断续看**：比赛记录在开赛瞬间写入服务端并带有真实开始时间。关闭页面、刷新或中途退出后，记录保持 `running`；回到航线图点击 **⏯ 续看**（或重开页面自动弹出）即可从当前时刻继续——比赛不会重开，奖励也不会提前落账。
4. **历史回放**：完赛后点击赛站的 **▶ 回放** 或「赛季之巅」战绩行上的播放按钮，可重放完整分段动画；回放只读记录，绝不重复结算。
5. **赛季推进**：每站完赛进度条 +1，6 站全部完赛为一季；各岛天气与难度不同（晴/风/雨/雾/雷暴，难度 ★1-★5）。
6. **机库**：查看飞艇四项性能（速度/转向/加速/耐久）与部件健康度；装备/卸下改装件（引擎/翼板/氮气/龙骨/护甲）；招募机师与技工；部件磨损可花费维护恢复至 100%。
7. **赛季之巅**：赛季积分达标可解锁赞助商奖励（资金 + 声望），并查看本赛季各站战绩与回放。

## 唯一比赛记录（race_records）

动画、LIVE 排名、断点续看、历史回放与最终奖励共用同一张 `race_records` 记录：

- `POST /api/races/:cid/start` 开赛时生成记录并锁定名次/奖励数据，状态为 `running`，**此刻不发奖**；同站同季唯一。
- 前端动画走完后调用 `POST /api/races/:id/finish`；服务端在事务中把记录从 `running` 原子迁移为 `completed`，迁移即结算闸门，重复调用直接返回 `already:true`，杜绝重复结算。
- `GET /api/races/active` 取进行中比赛用于续看；`GET /api/races/:id` 取历史记录用于回放；`viewed` 标记控制刷新后的自动弹出。
- 旧版 `race_log` 数据在启动时迁移为可回放的历史记录；越站脏数据继续按原规则回滚。

## 分段结算引擎

- 每段表现 = 对应属性（加速/转向/速度/耐久）× 该段权重 × 部件健康系数 × **该段天气系数**（雷暴在耐久段压制最强）+ 机师贡献（技巧/胆识/经验/心情）+ 技工贡献（技能/心情）+ 随机波动；装备的改装件按属性追加到对应分段。
- 4 段累计用时决定 1-6 名，对应 F1 式积分（25/18/15/12/10/8），并依名次与难度发放奖金；赛后飞艇部件按赛道难度与天气磨损，机师/技工心情随名次浮动。

## 数据表（SQLite）

`team` 车队资金/声望/积分 · `airships` 飞艇属性与部件健康 · `pilots` / `mechanics` 人员 · `upgrades` 改装件 · `circuits` 浮岛赛道 · `sponsors` 赞助商 · `race_records` **唯一比赛记录（分段数据快照 + 结算状态）** · `race_log`（旧版流水，启动时迁移）
