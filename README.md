# 🛸 天空之城 · 空中浮岛竞速经营

一款以**云海浮岛竞速**为核心玩法的经营模拟游戏。玩家经营一支空中竞速车队，在漂浮于云海的浮岛赛道上逐站参赛，赢取积分与奖金，改装飞艇、招募机师技工、达成赞助目标，向赛季之巅发起冲击。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务（server:4180 + vite:5204）
```

浏览器访问 **http://localhost:5204** 即可开始游戏。

> 若 5204 端口被占用，Vite 会自动切换到其他端口；后端 API 代理随之生效，无需手动修改。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3（`<script setup>`）+ Vite + Pinia |
| 后端 | Express + Node.js 内置 `node:sqlite` |
| 数据库 | SQLite（`server/sky.db`，首次启动自动建表并写入演示数据） |
| 启动 | `concurrently` 并行拉起前后端 |

## 玩法说明

1. **云海航线图**：主场景为云海浮岛赛季航线图，6 座浮岛依次排列。点击浮岛上的 **🚀 开赛** 进入分站竞速。
2. **分段分站竞速**：每站分 **启航段 / 中段云流 / 冲线段** 三段。6 艘飞艇（玩家 + 5 名对手）按各自分段用时推进，右侧 LIVE 榜实时刷新名次；每段发挥都受 **天气、已装备改装、部件健康、机师/技工状态** 共同影响，赛道上会弹出超车与天气事件横幅。
3. **中断续看**：开赛瞬间服务器即生成并落库一份完整比赛记录，动画只播不结算。中途退出或刷新页面后，航线图出现「比赛进行中 · 点击中断续看」浮条，赛站按钮变为 **▶ 续看**，从上次观赛进度继续。
4. **一次结算，杜绝重复**：比赛播完（或点「跳过动画直接结算」）才按该记录发放积分/奖金/磨损/声望；结算接口幂等，断线重放、重复点击都不会重复发奖。
5. **历史回放**：赛季之巅抽屉的每场战绩都可 **↻ 回放**，用同一份记录重放全场动画与排名，回放只展示结果、绝不再次结算。
6. **赛季推进**：每站完赛进度条 +1，6 站全部完赛为一季；各岛天气与难度不同（晴/风/雨/雾/雷暴，难度 ★1-★5）。
7. **机库**：查看飞艇四项性能（速度/转向/加速/耐久）与部件健康度；装备/卸下改装件（引擎/翼板/氮气/龙骨/护甲）；招募机师与技工；部件磨损可花费维护恢复至 100%。
8. **赛季之巅**：赛季积分达标可解锁赞助商奖励（资金 + 声望），并回放本赛季各站比赛。

## 竞速记录与结算引擎（单一事实来源）

- 开赛后一条 `races` 记录落库，内含三段全部赛艇的分段 pace/用时/入场时间、天气与发挥系数、**改装件快照**、**机师/技工状态快照**、分段事件（超车/天气）以及**预先确定的最终名次与奖励**。
- 动画、LIVE 实时排名、结算卡、历史回放**全部从同一份记录派生**，不存在各算各的导致「画面名次」与「结算名次」不一致的问题。
- 分段 pace：性能四项按段加权合成（启航拼加速、中段拼极速转向、冲线拼极速爆发），再乘 **部件健康系数**（地板 0.62）与 **分段天气系数**（雾/雷暴在中段、冲线段压制更大）；机师胆识提供天气抗性，机师带队加成与技工调校加成作为常数项叠加。
- 对手 AI 同口径计算天气抗性与机师/技工加成，并按赛站难度与随机档位拉开快慢差距：低难度多为教学局，高难度需靠改装与维护争胜。
- 名次 1-6 对应 F1 式积分（25/18/15/12/10/8）+ 名次奖金；赛后部件按赛道难度与天气磨损，机师经验/心情随之变化。
- 结算走数据库事务并以 `races.settled` 为唯一闸门，重复请求直接返回同一份结果（幂等），赞助商在同一事务内按积分对账。

## 比赛相关接口

| 方法与路径 | 说明 |
|-----------|------|
| `POST /api/races/start/:cid` | 开赛并生成完整比赛记录；该站已有 running 记录时返回同一份（续看） |
| `GET /api/races/:id` | 读取单场比赛记录 |
| `POST /api/races/:id/progress` | 上报观赛进度（秒），中断续看锚点，与结算无关 |
| `POST /api/races/:id/settle` | 按记录结算，幂等；只发一次奖 |

## 数据表（SQLite）

`team` 车队资金/声望/积分 · `airships` 飞艇属性与部件健康 · `pilots` / `mechanics` 人员 · `upgrades` 改装件 · `circuits` 浮岛赛道 · `sponsors` 赞助商 · `races` 比赛记录（分段过程/快照/奖励，running→settled，含观赛进度 watch_el）· `race_log` 结算流水（经 `race_id` 关联到对应比赛）
