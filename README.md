# 🛸 天空之城 · 空中浮岛竞速经营

一款以**云海浮岛竞速**为核心玩法的经营模拟游戏。玩家经营一支空中竞速车队，在漂浮于云海的浮岛赛道上逐站参赛，赢取积分与奖金，改装飞艇、招募机师技工、达成赞助目标，向赛季之巅发起冲击。

## 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务（server:4180 + vite:5204）
```

浏览器访问 **http://localhost:5204** 即可开始游戏。

> 若 5204 端口被占用，Vite 会自动切换到其他端口；后端 API 代理随之生效，无需手动修改。

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vue 3（`<script setup>`）+ Vite + Pinia |
| 后端 | Express + Node.js 内置 `node:sqlite` |
| 数据库 | SQLite（`server/sky.db`，首次启动自动建表并写入演示数据） |
| 启动 | `concurrently` 并行拉起前后端 |

## 玩法说明

1. **云海航线图**：主场景为云海浮岛赛季航线图，6 座浮岛依次排列。点击浮岛上的 **🚀 开赛** 进入分站竞速。
2. **分站竞速**：6 艘飞艇（玩家 + 5 名对手）从起点冲向终点线，右侧 LIVE 榜实时刷新名次；结束后弹出结算卡（名次 / 积分 / 奖金 / 部件磨损 / 声望）。
3. **赛季推进**：每站完赛进度条 +1，6 站全部完赛为一季；各岛天气与难度不同（晴/风/雨/雾/雷暴，难度 ★1-★5）。
4. **机库**：查看飞艇四项性能（速度/转向/加速/耐久）与部件健康度；装备/卸下改装件（引擎/翼板/氮气/龙骨/护甲）；招募机师与技工；部件磨损可花费维护恢复至 100%。
5. **赛季之巅**：赛季积分达标可解锁赞助商奖励（资金 + 声望），并查看本赛季各站战绩。

## 竞速结算引擎

- 飞艇基础性能由四项属性加权合成，再乘 **部件健康系数**（磨损越低发挥越差）与 **天气系数**（雷暴/雾天大幅削弱）。
- 机师（技巧/胆识/经验/心情）与技工（技能）提供额外增益。
- 每站与 5 名 AI 对手比拼，名次 1-6 对应 F1 式积分（25/18/15/12/10/8），并依名次发放奖金；赛后飞艇部件按赛道难度与天气磨损。

## 数据表（SQLite）

`team` 车队资金/声望/积分 · `airships` 飞艇属性与部件健康 · `pilots` / `mechanics` 人员 · `upgrades` 改装件 · `circuits` 浮岛赛道 · `sponsors` 赞助商 · `race_log` 战绩流水
